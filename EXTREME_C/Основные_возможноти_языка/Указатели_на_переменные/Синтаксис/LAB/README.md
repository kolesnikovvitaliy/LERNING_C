### 📋 Проверочная работа №1: «Связывание типов и обмен значениями»
**Задание:** Напишите функцию `swap_ints`, которая принимает два указателя на целые числа (`int *a` и `int *b`) и меняет местами значения переменных, на которые они указывают. В функции `main` продемонстрируйте её работу.

*   **Критерии успешности:**
    *   Значения переменных в `main` должны измениться.
    *   Сама функция `swap_ints` не должна возвращать значений (`void`).
    *   Запрещено использовать глобальные переменные.

<details>
<summary>💡 Подсказка по реализации</summary>

```c
void swap_ints(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}
```
</details>

### 📋 Проверочная работа №2: «Поиск и исправление ошибок (Найди баг)»
**Задание:** Данный код компилируется, но приводит к критической ошибке времени выполнения (Segmentation Fault) или непредсказуемому поведению. Найдите ошибку, объясните её причину и перепишите код правильно.

```c
#include <stdio.h>

void broken_function(void) {
    int *ptr = NULL;
    *ptr = 500;
    printf("Значение: %d\n", *ptr);
}

int main(void) {
    broken_function();
    return 0;
}
```

<details>
<summary>🔍 Решение и разбор бага</summary>

**Ошибка:** Происходит разыменование «дикого» (нулевого) указателя `*ptr = 500;`. Указатель `ptr` инициализирован как `NULL` и не ссылается на валидный участок памяти. Попытка записать туда данные вызывает краш программы.

**Исправление:** Перед разыменованием указателю нужно присвоить адрес существующей переменной:
```c
int var = 0;
int *ptr = &var;
*ptr = 500;
```
</details>

### 📋 Проверочная работа №3: «Арифметика указателей разных типов»
**Задание:** Напишите программу, которая создает массив из двух элементов `int arr[2] = {10, 20};`. Создайте указатель `int *ptr = arr;`. Используя **только** оператор инкремента `++` для указателя и оператор разыменования `*`, выведите на экран второй элемент массива (число 20).

*   **Дополнительный вопрос:** На сколько байт сдвинется указатель `ptr` при выполнении операции `ptr++` на 64-битной системе?

<details>
<summary>⚙️ Правильный ответ</summary>

```c
#include <stdio.h>
int main(void) {
    int arr[2] = {10, 20};
    int *ptr = arr;
    ptr++; // Сдвиг на sizeof(int), то есть на 4 байта вперед
    printf("Второй элемент: %d\n", *ptr); // Выведет 20
    return 0;
}
```
*Ответ на вопрос:* Указатель сдвинется на **4 байта**, так как тип `int` занимает 4 байта.
</details>

| Номер теста | Правильный ответ | Краткое объяснение |

| **1** | **B** | Указатель `p` хранит адрес `x`. Когда мы меняем саму `x = 30`, значение в этой ячейке памяти обновляется. Разыменование `*p` обращается к этой же ячейке и читает актуальное значение `30`. |

### ❓ Вопрос 1: Основы разыменования
Предположим, у нас есть следующий фрагмент кода:
```c
int x = 10;
int *p = &x;
x = 20;
printf("%d", *p);
```
**Что будет выведено на экран в результате выполнения этой программы?**
*   [ ] A) `10`
*   [ ] B) `20`
*   [ ] C) Адрес памяти переменной `x`
*   [ ] D) Ошибка компиляции

<details>
<summary>🔍 Нажмите, чтобы узнать правильный ответ</summary>

> **Правильный ответ: B**
>
> **Разбор:** Указатель `p` хранит адрес переменной `x`. Он является ссылкой на ячейку памяти, а не статичной копией данных. Когда мы изменили значение самой переменной `x = 20`, данные в этой ячейке обновились. Оператор разыменования (`*p`) обращается к этой же ячейке и читает уже актуальное значение — `20`.
</details>

### ❓ Вопрос 2: Типы указателей
Если переменная `var` имеет базовый тип `int`, то к какому типу данных относится выражение `&var` (взятие адреса)?
*   [ ] A) `int`
*   [ ] B) `void *`
*   [ ] C) `int *`
*   [ ] D) `char *`

<details>
<summary>🔍 Нажмите, чтобы узнать правильный ответ</summary>

> **Правильный ответ: C**
>
> **Разбор:** Оператор взятия адреса (`&`) возвращает адрес памяти переменной. В языке Си тип "адрес переменной типа int" строго обозначается как указатель на целое число — `int *`.
</details>

### ❓ Вопрос 3: Спецификатор `%p`
Для чего предназначен спецификатор формата `%p` при работе с функцией `printf()` в языке Си?
*   [ ] A) Для вывода одиночного символа (Pointer character)
*   [ ] B) Для вывода строки (Paragraph)
*   [ ] C) Для вывода адреса памяти в шестнадцатеричном формате
*   [ ] D) Для вывода числа с плавающей точкой (Percent)

<details>
<summary>🔍 Нажмите, чтобы узнать правильный ответ</summary>

> **Правильный ответ: C**
>
> **Разбор:** Спецификатор `%p` специально разработан для корректного и стандартизированного вывода значений указателей, то есть адресов памяти (обычно отображается в виде `0x7ff...`). Для символов используется `%c`, для строк — `%s`, а для чисел с плавающей точкой — `%f`.
</details>
