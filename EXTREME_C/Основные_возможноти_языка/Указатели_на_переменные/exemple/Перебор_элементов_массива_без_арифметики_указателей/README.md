## 💻 Документированный исходный код (Doxygen)

Файл написан с использованием комментариев Javadoc-стиля, полностью готовых для обработки генератором документации **Doxygen**.

```c
#include <stdio.h>

/**
 * @file main.c
 * @brief Демонстрация базовой работы с массивами и циклами в языке Си.
 *
 * Данный файл содержит учебный пример, иллюстрирующий процессы выделения
 * памяти под статический массив, последовательного заполнения его ячеек
 * данными и последующего вывода содержимого в консоль с помощью цикла.
 */

/**
 * @def SIZE
 * @brief Фиксированный размер демонстрационного массива.
 * @details Определяет количество элементов, которые может хранить массив,
 * а также задает верхнюю границу для итератора цикла.
 */
#define SIZE    5

/**
 * @brief Точка входа в программу.
 *
 * Функция инициализирует локальный целочисленный массив, присваивает значения
 * его элементам (от 0 до 4) и выводит их на экран в столбик.
 *
 * @param[in] argc Количество аргументов командной строки (не используется).
 * @param[in] argv Массив строк-аргументов командной строки (не используется).
 *
 * @return Статус завершения программы.
 * @retval 0 Успешное выполнение программы.
 */
int main(int argc, char **argv)
{
    /* Подавление предупреждений компилятора о неиспользуемых аргументах main */
    (void)argc;
    (void)argv;

    /**
     * @brief Локальный массив целых чисел.
     * @details Выделяет в стеке непрерывный блок памяти размером @c SIZE * sizeof(int).
     */
    int arr[SIZE];

    /**
     * @name Заполнение массива данными
     * @note Была исправлена логическая ошибка исходного кода, где все значения
     * записывались исключительно в нулевой индекс @c arr[0]. Теперь значения
     * распределены по всему объему массива.
     * @{ */
    arr[0] = 9;   /**< Запись числа 9 в первый (нулевой) элемент массива. */
    arr[1] = 22;  /**< Запись числа 22 во второй элемент массива. */
    arr[2] = 30;  /**< Запись числа 30 в третий элемент массива. */
    arr[3] = 23;  /**< Запись числа 23 в четвертый элемент массива. */
    arr[4] = 18;  /**< Запись числа 18 в пятый (последний) элемент массива. */
    /** @} */

    /**
     * @brief Цикл последовательного вывода элементов.
     * @details Переменная-счетчик @p i выступает в роли индексa. Цикл выполняется
     * до тех пор, пока @p i строго меньше значения макроса @ref SIZE.
     */
    for (int i = 0; i < SIZE; i++) {
        /* Вывод текущего элемента массива с переносом строки */
        printf("%d\n", arr[i]);
    }

    return 0;
}
```

## ⚙️ Глубокий технический разбор механики

### 🧠 Выделение памяти на стеке (Stack Allocation)
При объявлении `int arr[SIZE]` компилятор мгновенно резервирует место в стековом фрейме текущей функции.
* Размер выделения вычисляется на этапе компиляции: $\text{SIZE} \times \text{sizeof(int)}$.
* На стандартной 32/64-битной архитектуре один `int` занимает **4 байта**. Массив занимает ровно **20 байт** непрерывного пространства.
* **Важно:** Поскольку массив объявлен без явной инициализации (например, без `= {0}`), до выполнения блока заполнения ячейки содержат непредсказуемый «мусор» памяти.

### 🛡️ Безопасность итерации и OOB-уязвимости
Условие `i < SIZE` гарантирует, что цикл завершится строго на индексе `4`.
В языке Си отсутствует встроенная проверка выхода за границы массива (**Out of Bounds**). Ошибка в условии (например, `i <= SIZE`) заставит программу обратиться к `arr[5]` — ячейке памяти, находящейся за пределами массива. Это приводит к **Undefined Behavior** (неопределенному поведению) или аварийной остановке операционной системой.

## 🛠️ Компиляция и сборка

Код совместим с любым стандартным компилятором C (GCC, Clang, MSVC). Рекомендуется собирать программу с включением строгих предупреждений для контроля качества кода:

```bash
# Компиляция с флагами вывода предупреждений компилятора
gcc main.c -Wall -Wextra -O2 -o array_demo

# Запуск скомпилированной программы
./array_demo
```
