# 🚀 Advanced ANSI C Color Logger


Компактная, быстрая и гибкая система логирования для проектов на языке **C**. Модуль поддерживает цветовую разметку терминала с помощью ANSI-последовательностей, фильтрацию сообщений по уровням важности (verbosity) и динамическое управление конфигурацией во время выполнения.

## 🎨 Поддерживаемые уровни и цвета

Логгер поддерживает 7 уровней важности. Каждый уровень обладает своим строковым представлением и цветовой палитрой для удобного визуального анализа логов:

| Индекс | Уровень лога | Назначение | Цвет в консоли |
| :---: | :--- | :--- | :--- |
| **0** | `NONE` | Системный уровень (сообщения игнорируются) | По умолчанию |
| **1** | `PRINT_RESULT` | Вывод чистых результатов без префиксов | Заданный макросом |
| **2** | `ERROR` | Критические ошибки и сбои приложения | 🔥 Красный |
| **3** | `INFO` | Информационные сообщения о штатной работе | 🍏 Зеленый |
| **4** | `WARNING` | Предупреждения о потенциальных проблемах | ⚠️ Желтый |
| **5** | `TRACE` | Глубокое пошаговое трассирование | 🔍 Синий / Голубой |
| **6** | `DEBUG` | Отладочная информация для разработчиков | ⚙️ Серый / Фиолетовый |

## 🛠️ API Справочник

### 1. Вывод лога
```c
void log_message(log_level_t level, const char *fmt, ...);
```
Главная функция системы. Принимает уровень важности, строку форматирования и вариативный список аргументов.
* **Безопасность:** Потокобезопасность зависит от реализации `vprintf` в стандартной библиотеке вашей ОС.
* **Особенность:** Автоматически форматирует вывод под текущую конфигурацию терминала.

### 2. Изменение уровня "на лету"
```c
log_level_t set_log_level(log_level_t level);
```
Динамически изменяет текущий глобальный порог `current_log_level`.
* **Возвращает:** Предыдущее значение уровня (удобно для временного переключения режимов).

## 💻 Примеры интеграции и использования

### Базовый пример использования

```c
#include "my_logger.h"

int main() {
    // По умолчанию установлен уровень DEBUG — видны все логи
    log_message(INFO, "Запуск системы инициализации...");
    log_message(WARNING, "Низкий уровень свободной памяти: %d МБ", 128);
    log_message(ERROR, "Не удалось подключиться к серверу %s на порту %d", "127.0.0.1", 8080);

    // Вывод чистых данных (например, таблицы)
    log_message(PRINT_RESULT, "Результат вычислений: X = %.2f\n", 42.42);

    return 0;
}
```

### Временное переключение уровня (Паттерн "Scoped Log")

Если вам нужно заглушить лишние логи или, наоборот, детально исследовать конкретный участок кода:

```c
void critical_section() {
    // Временно включаем режим ERROR, чтобы скрыть INFO/DEBUG сообщения
    log_level_t previous_level = set_log_level(ERROR);

    // ... этот код производит много логов, но мы увидим только ошибки ...
    log_message(INFO, "Этот лог не напечатается");
    log_message(ERROR, "А этот лог напечатается, если возникнет сбой!");

    // Восстанавливаем исходный уровень логгера
    set_log_level(previous_level);
}
```

## ⚡ Особенности реализации и Warnings

> ⚠️ **ВАЖНОЕ ПРЕДУПРЕЖДЕНИЕ**
>
> 1. **Перенос строки (`\n`):** Функция `log_message` автоматически добавляет символ новой строки `\n` перед префиксом для уровней `ERROR` и выше. Однако для текста сообщения пользователя символ `\n` должен передаваться внутри строки форматирования `fmt`.
> 2. **Сброс цвета:** В конце каждой итерации функция выполняет принудительный сброс цвета через макрос `CLR_RESET`. Убедитесь, что этот макрос корректно определен в вашем заголовочном файле `my_logger.h`.
