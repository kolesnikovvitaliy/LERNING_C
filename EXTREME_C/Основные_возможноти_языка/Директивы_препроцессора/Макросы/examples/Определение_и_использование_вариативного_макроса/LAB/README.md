
### Список проектов: Определение и использование вариативного макроса

В данном разделе представлены проекты на языке C, демонстрирующие работу с **вариативными макросами** (`variadic macros`). Эти инструменты позволяют передавать произвольное количество аргументов в препроцессор с помощью идентификатора `__VA_ARGS__`.

#### 1. [lab_main - Приемер и описание кода лабораторной работы](https://github.com/kolesnikovvitaliy/LERNING_C/tree/main/EXTREME_C/Основные_возможноти_языка/Директивы_препроцессора/Макросы/examples/Определение_и_использование_вариативного_макроса/LAB/lab_main)
* **Назначение**: Демонстрация базового синтаксиса и возможностей вариативных макросов.
* **Описание**: Проект содержит примеры создания макросов для гибкого форматирования строк.
* **Ключевые концепции**: Идентификатор `__VA_ARGS__`, оператор `##__VA_ARGS__` для обработки пустого списка аргументов, строковая подстановка.

#### 2. [logger - Полнофункциональный консольный Логгер: часть практической работы](https://github.com/kolesnikovvitaliy/LERNING_C/tree/main/EXTREME_C/Основные_возможноти_языка/Директивы_препроцессора/Макросы/examples/Определение_и_использование_вариативного_макроса/LAB/LOGGER)
* **Назначение**: Практическое применение вариативных макросов для создания системы логирования.
* **Описание**: Модуль для вывода диагностических сообщений разного уровня важности (`NONE_LOG` `PRINT_RESULT` `DEBUG_LOG`, `INFO_LOG`, `ERROR_LOG` `WARNING_LOG`). Макросы автоматически собирают контекст вызова и передают форматированный текст в потоки вывода.
* **Ключевые концепции**: Уровни логирования, макросы-обертки над семейством функций `vfprintf`, условная компиляция для оптимизации сборки.
